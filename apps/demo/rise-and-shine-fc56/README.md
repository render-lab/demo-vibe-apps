# rise-and-shine-fc56

A one-page static brochure site for a neighborhood bakery, presenting the menu, hours, and location. All content is fixed and read-only with no transactions or persisted user data, so a single static_site fully serves the prompt—no backend or database is warranted.

Generated by vibe-coding-app from the prompt: "Build a one-page website for a neighborhood bakery called Rise & Shine, with the menu, hours, and location."

## Infrastructure

- vibe-demo-rise-and-shine-fc56-web (static)

## Deploying this app on its own

It is already deployed as part of the factory's Blueprint at the
repository root. To run it as its own Blueprint instead, create a new
Blueprint from https://github.com/render-lab/demo-vibe-apps with the Blueprint Path set to:

```text
apps/demo/rise-and-shine-fc56/render.yaml
```
